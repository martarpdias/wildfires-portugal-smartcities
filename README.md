# Wildfires in Portugal — Smart Cities Final Project

**Data Science Lab for Smart Cities** | Università degli studi di Milano-Bicocca  
Inês Maneta · João Pedro Sousa · Marta Dias · Rita Pinto

---

This project analyses wildfire risk and prevention infrastructure in Portugal, 
examining whether the most economically vulnerable municipalities face the 
greatest gaps in wildfire prevention coverage. The analysis is implemented 
in Python using open geospatial data from ICNF and INE, and combines a 
national wildfire risk model with social vulnerability indicators to identify 
priority areas for policy intervention.
